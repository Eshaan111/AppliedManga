DINOv2 character identity — manual annotation

Choose a crop style, then draw characters in the same order on every page: A, B, C… Boxes save automatically in drawing-order mode.

Position 1 = A, 2 = B, etc. Use the same character order across pages and crop styles within a sequence. Skip missing characters to keep later positions aligned. Earlier crop styles for the selected position are highlighted: purple = face, blue = head + hair. After each box, enter the character's name in the popup to save. Export to disk before closing. Replace this experiment's annotations/characters.json with your export. A browser autosave is also kept on this machine.
